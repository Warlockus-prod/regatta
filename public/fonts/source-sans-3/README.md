# Source Sans 3

Unmodified Adobe Source Sans 3, pinned to commit `87b37a2daaed80fcb8e8ccb0085c4d72ddade12e` from
https://github.com/adobe-fonts/source-sans. SIL Open Font License 1.1 is retained in LICENSE.md.

The variable upright WOFF2 is served locally on the web and embedded into the offline sailing/race HTML.
The full Regular (400), Semibold (600) and Bold (700) TTFs are copied into mobile/assets/fonts for native text.
No external font service is requested at runtime. Actual TTF cmap coverage was checked for RU, EN, PL, ES, FR, DE and IT samples recorded in manifest.json.
