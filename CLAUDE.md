# Claude-специфичные заметки

Все правила проекта живут в `AGENTS.md` (импортирован строкой выше), карта кода
в `ARCHITECTURE.md`, история в `CHANGELOG.md`. Здесь только то, что касается
Claude Code и не имеет смысла для других агентов.

- Прочитай `AGENTS.md` до начала работы, а `CHANGELOG.md` раздел `## Unreleased`
  до первого коммита: там текущее состояние ветки.
- `PATTERNS.md` - дверь перед словом "готово" (D1-D6 продублированы в
  `AGENTS.md`, раздел "Правила работы"). Читай его в начале сессии.
- Проверка в браузере обязательна для UI-правок: Playwright MCP или
  `npx playwright test`, включая мобильный вьюпорт. Свежая вкладка: консоль
  повторяет старые ошибки из буфера.
- В ворктри пути вида `/Users/Andrey/App/all/regatta/src/...` ведут в ОСНОВНОЙ
  чекаут, а не в ворктри. Проверяй путь перед правкой, тестом и запуском
  сервера.
- После squash-merge ветка ворктри не сливается повторно: `git fetch && git
  reset --soft origin/main`, затем новый коммит и force-push в свою ветку (не в
  `main`).
- Карта проекта поддерживается по правилу из `AGENTS.md` ("Правило поддержки
  карты"), гейт - `npm run check:map`.
