### /simulator-v3 - V3 Cockpit

**Desktop (1280x800):** layout renders correctly:
- 4 pods in corners (WIND, MAIN, JIB, VIEW)
- Scene center with TopScene (boat, vectors, overlays)
- Metrics strip (speed, heel, AWA, trim)
- Single commentary line

Toggle "Сзади" switches to rear view correctly - heel visible, horizon
level, numeric label "X°" bottom-right.

Button "Оптим" applies recommended trim. After click: speed goes from
2.8 kt -> 6.1 kt, trim 46% -> 100%, both sail statuses flip from red
"СРЫВ" to green "ТЯНЕТ", commentary updates to "Слот здоров".

Glossary footer at bottom: button "▸ Что означают все эти сокращения?"
expands to show 14 terms (TWS, TWA, AWS, AWA, VMG, Heel, Leeway, Slot,
Stall, Drive, Side, AoA, Optimum, Trim). Works.

**Bug found (user-visible):** the page loads with both sails in STALL
state. Commentary shows "Грот перетянут". Speed is only 2.8 kt, trim
46%. Root cause: `DEFAULT_UI.jibAngle = 42` is too tight for TWA=90.
At the low initial boat speed, AWA stays close to TWA = ~76°, so jib
AoA = 76 - 42 = 34° (past stall). The engine settles into a
stalled equilibrium.

**Fix applied this session:**
- Bumped defaults to `mainAngle: 52, jibAngle: 54` (matches
  recommendedTrim for a sane beam reach).
- Raised initial-bs seed in `createInitialState` from 1.8 to 3 kt,
  scale 0.28 -> 0.45 per TWS, so settle() starts above the stall
  attractor.
