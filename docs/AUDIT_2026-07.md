# Full app audit - 2026-07 (findings + fix log)

A multi-agent audit (code, security, i18n, UX, a11y, theme, perf, mobile,
physics, testing) produced 130 findings; 24 high-severity confirmed, 0 critical.
This file records what was fixed and what remains, so the deferred cross-lane
items are not lost.

Baseline health: tsc clean, physics 23/23, api 35/35, e2e 9/9.

## Fixed and shipped (Shared / web lane)

1. i18n correctness
   - checklist ES safety warning "boton" (button) -> "botavara" (boom).
   - /api/ai-chat: accept all 7 langs (es/fr/de/it were answered in Russian).
   - leaderboard mission chips -> legacyPick (PL saw Cyrillic); cancelled-flag
     guard against out-of-order leaderboard fetches.
   - glossary search now matches ES/FR/DE/IT term + definition.
2. Light theme legibility (semantic tokens: --cat-*, --hover-bg, --border-subtle;
   AA-darkened light --text-muted and --accent-cyan)
   - courses compass: white masts -> var(--sail-color); neon point colors via a
     tc() mapper -> var(--cat-*); white silhouettes/track/dots -> neutral gray.
   - glossary category colors + literals; BootcampFooterNav bar theming (and
     hidden on immersive routes so it stops covering game controls); rules
     diagram panel pinned dark; AnatomyPosters caption; SiteFooter; /support
     inputs; Navigation hover; StatsDashboard chips; YachtViewer3D backdrop.
3. Web pages
   - ContentFooterNav: /support + /privacy entries (were showing onboard nav).
   - stale copy: /checklist "progress saved" and /anatomy "2D profile" corrected.
   - bootcamp completion CTA -> /simulator (V1) instead of WIP /simulator-v3.
4. Security
   - leaderboard API no longer returns raw session sid; isMe computed server-side.
   - /api/feedback truncates stored client IP (shared src/lib/net.ts helper).
   - /api/og/result: per-IP + global rate limit and bounded query params.
5. CI
   - deploy.yml build-check now runs check:dash + test:api on every main push.
   - cyrillic-scan.mjs exits non-zero on real leaks; added /support to routes.
6. Performance / infra
   - nginx now long-caches /gallery /models /anatomy /brand (7-day Cache-Control,
     applied live on vps2 to both vhosts via proxy_hide_header + add_header).
   - gallery collage strip loads eager (LCP); .dockerignore raw _incoming.
7. Accessibility
   - FeedbackWidget: dialog role + aria-modal, Escape to close, focus move/restore,
     localized close label; skip-to-content link + <main id>.
8. Multiplayer (ws-server)
   - per-IP WS message cap 60 -> 240/s so 3+ players behind one NAT are not throttled.
9. Mobile (applies on next build)
   - coach.ts: 30s timeout for /api/coach (was aborting at 8s mid-generation).
   - app.json: declare Product Interaction + Crash Data in the iOS privacy
     manifest (was empty while shipping PostHog) to avoid metadata rejection.

## Deferred - need a live test in their own lane (not blind-shipped)

Multiplayer / game (ws-server + GameClient, needs a running multiplayer test):
- ws-server broadcasts each player's sid as the public id (impersonation vector).
  Fix: opaque per-room id, keep sid server-side only. Touches the client protocol
  (MultiplayerClient.tsx), so it needs a coordinated client+server change + test.
- ws-server memory leaks: write-only `disconnected` map, never-evicted ipHits,
  orphan rooms.
- GameClient autopilot: stale closure in the rAF loop (never steers/disengages).
- Russian-only strings leak to all langs in GameClient replay overlay + ws-server
  mission reasons; race-result OG share image is hardcoded Russian.
- Educational inconsistency: theory teaches a 45-degree no-go zone, the game uses 30.
- Game physics duplicated in 3 manually-synced copies (GameClient, race-physics.ts,
  ws-server) with tests on only one.

Mobile (needs the mobile checkout + iOS simulator):
- Leaderboard writes 400 (no regatta_sid cookie sent) while copy invites play.
- Gallery: 73 remote images in an unvirtualized ScrollView, no loading/error state.
- Settings resets bypass hooks; "Clear all data" re-enables analytics for opt-outs.
- Release gate G3/G4 tooling (fastlane/, codemagic.yaml) does not exist yet.

Larger web items still open:
- /checklist bullet items untranslated for ES/FR/DE/IT (extract to src/data).
- 566 tp() call sites without es/fr/de/it extras on core learning routes.
- Modal a11y (OnboardingTour, HelpOverlay, AnatomyPosters lightbox) lacks focus
  trap/restore; hardcoded English aria-labels on Navigation.
- E2E runs post-deploy only; move a local `next start` Playwright pass pre-deploy.
