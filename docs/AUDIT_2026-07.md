# Full app audit - 2026-07 (findings + fix log)

A multi-agent audit (code, security, i18n, UX, a11y, theme, perf, mobile,
physics, testing) produced 130 findings; 24 high-severity confirmed, 0 critical.
This file records what was fixed and what remains, so the deferred cross-lane
items are not lost.

Baseline health: tsc clean, physics 23/23, api 35/35, e2e 9/9.

## Fixed (game / ws-server lane) - 2026-07-05

All six deferred multiplayer/game items were fixed and verified with a live
harness (ws-server on :3001 + `next start` on :3000 + two protocol/browser
clients creating and joining a room).

- SECURITY (was HIGH): ws-server no longer broadcasts the player sid. A new
  `genPlayerId()` mints an opaque per-room id; the sid stays server-side (resume
  matching + the leaderboard POST cookie only) and appears in no frame. The
  client keys "me" off the server-assigned opaque id. Verified: two-client
  protocol harness, zero sid bytes across every frame to every peer, reconnect
  returns the same opaque id, and the leaderboard POST still saved (Next logged
  `race-result.saved`).
- ws-server memory leaks: dropped the write-only `disconnected` map (the grace
  timer now lives on the Player and is cancelled on reconnect / room teardown via
  a `destroyRoom` helper), added a periodic `ipHits` sweep, and confirmed rooms
  drain back to 0 after leave+close. (The per-IP cap was already 240/s, shipped.)
- GameClient autopilot stale closure: the rAF loop now reads `autopilotOnRef`
  (synced from state + set on the button). Verified in-browser: engage shows
  "AUTO on", a manual turn disengages it, the button toggles both ways.
- i18n: GameClient ReplayOverlay uses the coach* localized helpers + a tp()'d
  ghost label; ws-server mission reasons are now stable CODES localized on the
  client (`missionReasonText`); `/api/og/result` takes `?lang=` (7 langs, ru
  default for legacy links). Verified: EN share card renders with no Russian; the
  finished frame carries no Cyrillic.
- Educational no-go zone reconciled to 30 degrees (theory -> game, per product
  call): `sailing-data.ts` in-irons/close-hauled angles + the no-go glossary now
  say 30, matching the game physics and its in-briefing "+/-30 deg" text. V3
  runtime tests stay green.
- Physics de-duplicated: GameClient imports the pure functions from
  `@/lib/race-physics`; the ws-server keeps its ESM mirror, now guarded by a
  vitest drift test (`src/lib/race-physics.drift.test.ts`, run by
  `npm run test:physics`) that fails if the two copies diverge numerically.
