## Bugs found this session (all fixed + re-verified)

### Bug 1: V2 "This page couldn't load" in production

**Found by:** Playwright console read on first browser visit.
**Root cause:** Drei `<Environment preset="sunset">` fetches HDR from
`raw.githack.com`, blocked by our nginx CSP which only allows `'self'`.
**Fix:** removed `Environment`, kept `Sky` + ambient + directional lights
(all local, CSP-safe).
**Verified:** live page loads after deploy, 0 console errors.

### Bug 2: V3 default loaded into stall

**Found by:** Playwright screenshot of default state showed red "СРЫВ" on
both sail pods, speed 2.8 kt, trim 46%.
**Root cause:** `DEFAULT_UI.jibAngle = 42` too tight. Engine seed speed
was `max(1.8, TWS*0.28)` = 3.4 kt; at that bs, AWA stayed near TWA (~76°),
so jib AoA = 76-42 = 34° (past 20° stall onset). Engine settled into a
starved low-speed attractor.
**Fix:** defaults to `mainAngle=52, jibAngle=54`; bumped engine seed to
`max(3, TWS*0.45)` = 5.4 kt for TWS=12.
**Verified:** 6.1 kt, trim 90%, both sails "ТЯНЕТ", slot healthy.

### Bug 3: /courses sector thumbnails all identical (boat always pointing up)

**Found by:** User comparison of thumbnails.
**Root cause:** `SailAngleIllustration` drew the boat with bow always up;
only the sail angle changed. All 5 courses looked geometrically identical.
**Fix:** wrapped hull + mast + sails in `<g rotate(twa)>`. Each course
now shows the boat at its actual angle to the (always-top) wind arrow.
Added bow marker dot. Moved speed indicator dots to fixed screen-frame
position.
**Verified:** thumbnails visibly differ - in-irons up, close-hauled
tilted, beam reach horizontal, broad reach aft-angled, running downward.

### Bug 4: /courses tack labels overlapping "Галфвинд" labels on mobile

**Found by:** User screenshot on narrow mobile.
**Root cause:** "ПРАВЫЙ ГАЛС" and "ЛЕВЫЙ ГАЛС" drawn vertically
(`transform="rotate(90)"`) at east and west outside the circle, same
vertical band as horizontal "Галфвинд" sector labels. On narrow widths
the rotated vertical text and horizontal Russian label collided.
**Fix:** moved tack labels to the BOTTOM of the diagram, horizontal,
at `cy + mainR + 62`. Clear of all other labels.
**Verified:** on 420x800 and 320x568 viewports, no overlap at all.

### Bug 5: V1 sail rendered on WINDWARD side (physically wrong)

**Found by:** User looking at canvas with wind from top, boat heading
east, noticed sail curving into the wind.
**Root cause:** `getTackSide(boatHeading, windDir)` used the wrong sign
of the difference, returning the opposite tack. The sail-rendering
logic uses `tackSign` from this to choose which side the sail extends
to. Flipping the tack meant sail extended to windward.
**Fix:** changed `normalizeAngle(boatHeading - windDir)` to
`normalizeAngle(windDir - boatHeading)`.
**Verified:** default state now displays "Правый" tack (was "Левый"),
matching the wind-on-starboard side geometry. Sail goes north when wind
is from south (leeward = correct).

### Bug 6: V3 jib looks flat, not inflated like a sail

**Found by:** User looking at V3 scene: "штаксель ведь не плоский а как
парус надутый просто сильнее или ослаблен."
**Root cause:** Jib SVG path used a single Q curve with small control-
point offset (sailSide * 22). Main sail similar. Both drew as thin
crescents without visible belly.
**Fix:** two Q curves per sail forming a pronounced out-and-back belly
shape. Added a linear gradient fill (`#dce7ee` -> `#ffffff` -> `#b9c9d4`)
so the luff side is slightly shaded, mid-sail is bright, leech edge is
slightly darker - reads as canvas under wind pressure.
**Verification:** build clean, pending post-deploy Playwright check.
