## Вывод

Проблема подтверждена. Основная часть радио остается польской по явно заданной политике в коде, а не из-за одного потерянного перевода. Сегодняшний PR #80 перевел только `/radio/symulator`. Переход из переведенного тренажера в первый урок, теорию, разговор, диктовку позиции или экзамен снова дает польский интерфейс для EN/ES/FR/DE/IT.

Английские реплики в эфире - отдельная осознанная настройка обучения международной радиосвязи. Ее не следует смешивать с языком инструкций. Польские оригиналы UKE можно сохранить для подготовки к польскому экзамену, показывая перевод и объяснение на языке ученика. Текущий код не предлагает такого полноценного перевода.

## Находки с доказательствами

### P1: политика языка блокирует большую часть локализации

`src/app/sternik/prefs.tsx:114` разрешает язык сайта только для `['/radio/symulator']`. Строка 128 принудительно выбирает PL для любого другого пути, если язык сайта не RU. Это действует и на web, и на shared offline bundle.

У пользователя DE/EN/... навигация внутри одного курса меняет язык. На `/radio/symulator` карточки первых шагов, диалогов и диктовки уже переведены, но адрес назначения снова попадает в польскую область. Нельзя исправить это одним удалением scope: данные теории, уроков и диалогов физически имеют только PL/RU.

Данные: `src/app/radio/teoria/courseData.ts:4`, `obsluga/lessonData.ts:16`, `rozmowa/dialogues.ts:35`, `pozycja/drillData.ts:53`, `zadania/tasks.ts:10`.

Прямой HTTP-показ текущего local server:

- `/radio?lang=de`: `<html lang="de">`, внутренний `<div lang="pl">`, H1 `Od zrozumienia systemu do pewnej pracy w eterze`.
- `/radio/symulator?lang=de`: `<html lang="de">`, внутренний `<div lang="de">`, H1 `Übung am ICOM-Funkgerät`.
- Title обоих ответов остается `Radio VHF i świadectwo SRC - symulator ICOM | Week to Regatta`.

### P1: русский тренажер не русский при чистом запуске

`src/app/sternik/prefs.tsx:45`: `DEFAULT_EXPL = 'pl'`. `src/app/radio/symulator/page.tsx:76` показывает RU только при `explLang !== 'pl'`; строки 81-88 возвращают польский текст задания по умолчанию. Даже после PR #80 выбор RU в глобальном переключателе не означает русские инструкции в радио.

Похожая политика используется в уроках и диалогах. Для новой цели пользователя нужен язык обучения из глобального языка, а польский оригинал/экзамен - отдельная явная опция. Сохраненные предпочтения и прогресс нужно мигрировать, а не просто сбрасывать.

### P1: приложение возвращает польский в новом локализованном тренажере

`mobile/scripts/build-radio-offline.mjs:65` подменяет общий `VoicePtt` на `OfflineVoicePtt.tsx`. В `mobile/scripts/offline-radio/OfflineVoicePtt.tsx:70,89,107,121,127` все строки выбираются по `ru ? RU : PL`, без языка приложения.

Конкретно EN/ES/FR/DE/IT увидят `Etap głosowy bez oceny sieciowej`, `Następna linia`, `Wypowiedziałem komunikat` и польское объяснение ограничений. Содержимое учебной радиопередачи остается английским.

Текущий пакет актуален по сборочной проверке, поэтому проблема действительно включена в артефакт, а не вызвана забытым rebuild.

### P2: RU-результаты голоса и все журналы не адаптированы

- `src/app/radio/symulator/trainerText.ts:65-66`: `checkLabel()` специально возвращает исходную польскую подпись для RU. Например, интерфейс может быть русским, а недостающий элемент и чек-лист - польскими.
- `src/app/radio/symulator/radioModel.ts:378`: `Power ON - watch on CH 16 / CH 70 (DSC)`.
- `radioModel.ts:495`: `CH 16 selected for the voice MAYDAY; DSC repeat remains active`.
- `radioModel.ts:616`: `SCAN needs a closed squelch - set SQL above OPEN`.
- `radioModel.ts:674`: английское объяснение срока ручной позиции.
- `src/app/radio/symulator/page.tsx:217` копирует эти строки без преобразования; `:1101` выводит raw `r.text`.
- `obsluga/InteractiveRadioCourse.tsx:346` также копирует raw device log.

Названия кнопок на настоящей ICOM-панели можно оставлять как на устройстве. Полные учебные предложения в журнале должны иметь переводы. Устойчивое решение - события с id/параметрами и локализатор в UI, а не хранение только готового английского предложения.

### P2: банк вопросов не содержит даже русских объяснений

`src/data/src-radio.ts:16-24`: модель вопроса имеет только `q`, `options`, `whyPl`, без locale map или `whyRu`. `src/app/radio/test/page.tsx:287-290,340,347,378` выводит польский оригинал и пояснение. Строка 381 прямо сообщает RU-пользователю, что пояснения только на польском.

Поэтому RU-переключатель пояснений не переводит банк. Для полноценной адаптации нужны отдельные переводы вопросов/вариантов и учебных объяснений при сохранении оригинала и правильных индексов.

### P2: офлайн-проверка микрофона дает английский fallback

`mobile/scripts/offline-radio/OfflineMicCheck.tsx:15-21` использует простой `tp(ru,en,pl)`, без ES/FR/DE/IT. Локальный `pick()` в `mobile/scripts/offline-radio/i18n.tsx:35-38` для отсутствующих extra возвращает EN. Те же принципы нужно проверить во всех offline-only уведомлениях при расширении языковой области.

### P2: тесты пока проверяют словари, а не полный путь пользователя

`src/app/radio/symulator/trainerText.test.ts:15-33` собирает известные тексты сценариев, Inspect и чек-листов. `:36-39` перечисляет общий web UI. OfflineVoicePtt, OfflineMicCheck, radioModel device log, metadata и остальные страницы радио туда не входят.

Тест гарантирует наличие и сохранность выбранных переводов, но не гарантирует отсутствие польского/английского на экране. Он не является редакторской проверкой естественности каждого перевода.

### P3: metadata, предпочтения и голос нуждаются в согласованной политике

- `src/app/radio/layout.tsx:6-12`: title/description/keywords всегда PL, включая уже переведенный тренажер.
- `mobile/scripts/offline-radio/i18n.tsx:58-66`: отдельный сохраненный выбор языка курса v2 имеет приоритет над языком приложения. Это может быть намеренным предпочтением, но для ожидания "каждый экран на выбранном языке приложения" поведение требуется пересмотреть.
- `src/app/api/radio-voice/route.ts:136`: STT всегда English. Это согласуется с модельными VHF-репликами, а не с языком пояснений.
- `src/app/api/radio-transcribe/route.ts:123-125`: поддерживаются только EN и PL; радиодиалоги отправляют EN.
- `src/app/api/radio-tts/route.ts:40`: стиль всегда `You are a Polish coast radio station operator on marine VHF.` и принимает только текст без venue/locale. После добавления Солента, Пальмы и Бодрума это единый польский оператор для всех мест. Это не причина польского текста интерфейса, но отдельный пункт реалистичности аудио.
- `src/app/radio/symulator/VoicePtt.tsx:168` показывает серверный `data.error` как есть; ряд ошибок API - английские. Нужны стабильные error codes и клиентский перевод.

## Что остается кроме языков

Подтвержденные ограничения, а не отсутствующая работа целиком:

1. EPIRB/SART задания 23-26 имеют текстовые процедуры; интерактивного устройства нет.
2. Входящие вызовы в receiving-сценариях стартуют в готовом состоянии; случайный/отложенный вызов посреди ожидания и DSC distress-relay еще остаются в roadmap (`docs/design/sternik-radio.md:753-761`).
3. В банке все еще ровно три `confidence: 'unsure'`: `src-1-36`, `src-2-24`, `src-2-25` (`src/data/src-radio.ts:500,2606,2619`). Нужен предметный разбор с инструктором; это не переводческая задача.
4. Голосовой этап без сети является самопроверкой по строкам. Приложение честно не имитирует распознавание и оценку; двусторонний разговор и серверная оценка требуют сети.
5. Новые регионы применены к сценариям тренажера; уроки устройства, разговор и диктовка позиции остаются Гданьским заливом и PL/RU. Это прямо записано в `docs/design/sternik-radio.md:973`.
6. Старые roadmap-строки о голосовом экзамене/деплое нельзя принимать за актуальную блокировку без повторной проверки: экзаменационный голосовой режим уже есть в `VoicePtt`, а инфраструктура менялась после написания документа.
