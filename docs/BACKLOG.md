# Regatta: рабочий список

Единственный рабочий список проекта. Переписан 2026-11-02 по указанию владельца
(2026-11-01): «переписать весь список и делать все по порядку; где что-то
отстает, синхронизировать, лишнее удалить; идти по порядку, все внедрить,
протестировать». Сюда сведены прежний бэклог (128 пунктов, 37 решений), оба
аудита 2026-11-01, план логики гонки, бэклог гавани, план игры 2026-10-30 и
старые списки открытого (раздел 6). Другие документы открытые пункты больше не
ведут, у них стоит ссылка сюда.

## 1. Как работаем

1. Один список, сверху вниз: берем верхний незакрытый пакет, доводим до
   «Готово, когда», отмечаем в разделе 4 с хешем коммита, идем к следующему.
2. Сначала приложение (TestFlight со всем сделанным), сайт обновляем, когда
   приложение устоялось и работает гладко.
3. Проверки только локально на Mac (`AGENTS.md`, «Как тестировать»); GitHub
   хранит код, workflows запускаются только вручную; деплой и загрузка в
   TestFlight только с явного «да» владельца.
4. Решения владельца помечены `[Р-N]` и собраны в разделе 3, рекомендация
   первой; пакет, который ждет решения, не начинаем угадыванием.
5. Приоритет: P0 блокирует выпуск сейчас, P1 следующий шаг, P2 этот квартал,
   P3 позже. Объем: S до дня, M 2-5 дней, L 1-3 недели, XL больше.

Сокращения в «Готово, когда»: **локальный гейт** = `npx tsc --noEmit`,
`npm run build`, `npm run test:physics`, `npm run test:api`,
`npm run test:radio`, `npx vitest run src/app/sternik`, `npx vitest run`,
`npm run test:multiplayer`, `npx playwright test` на прод-сборке,
`npm run check:dash`, `npm run check:map`; **мобильный гейт** = `cd mobile &&
npm run check` плюс гейт G1-G5 из `docs/design/mobile/RELEASE_CHECKLIST.md`.

### 6. [P1] ADR физики хода: сопротивление, крен, мертвый сектор, цена поворота

Цель: физика перестает учить ложному (эксперт A4-A7, раздел 4). От этого
зависят BEST VMG, кнопка поворота, штрафные обороты и манёвры под парусом с
остановкой, поэтому пакет стоит раньше руля и раньше медалей M5.

- Один новый ADR в `DECISIONS.md` (правило 8 `AGENTS.md`), физика отдельной
  фазой без UI (правило работы 1):
  - сопротивление корпуса: трение `k_f v^2` (около 55) плюс остаточное по
    числу Фруда (форма серии Delft), убрать потолок 1.25 корпусной скорости
    (`simulate.ts:191-200`), калибровка по сертификату ORC крейсера 40-46 фт;
  - штраф за крен (сопротивление `1 + k*heel^2`) и депауэр в `trimForDrive` с
    мягким потолком крена 25 град: риф окупается с 16-20 уз;
  - порог заполаскивания, `jibMinOff` около 10 град, Cl к нулю ниже входного
    угла профиля, сопротивление полощущей ткани: мертвый сектор из физики;
  - цена поворота: сопротивление руля от квадрата перекладки, проход линии
    ветра не быстрее 3-4 с, перенос шкота 3-5 с (это прежний ADR «цена
    поворота», разведка `docs/audits/2026-10-30/m0-13-tack-cost.md`).
- Контракты как тесты (D1, три входа): 6 уз ветра галфвинд не меньше 5.5 уз;
  20 уз галфвинд не больше 9 уз; бакштаг 120 град в 12 уз не медленнее 95 %
  галфвинда; лучший угол по ветру в 8 уз в коридоре 145-165 град; TWS 12 уз и
  TWA 25 град меньше 1 уз; лучший VMG против ветра в коридоре TWA 40-45 град;
  при 20 уз лучший VMG у рифа 0.5, при 25 уз у рифа 1; поворот при 12 уз
  стоит 1-2 корпуса.
- Одна константа бейдевинда и мертвого сектора вместо пяти (30 / 35 / 40 /
  42 / 45: упражнения, боты, квиз, судья, тексты), после правки она совпадает
  с физикой.
- Судья: «в повороте» по состоянию маневра, а не по `|TWA| < 42`
  (`race-rules.ts:82`), угловой порог 25-30 град.
- Ветер метрической гонки: заходы и порывы с периодами 120-480 с, сценарий
  устойчивого захода (`race-solo-wind.ts`, `windAt`).
- Тренажер: твист по U-образной кривой от ветра (`trim-heuristics.ts:34-35`),
  бонус щели на стаксель или пару с честной подписью (`forces.ts:198-224`,
  `slot-lesson.ts`).
- Перегенерировать серверную физику (`node scripts/build-race-server.mjs`),

Чтобы никто не добавил снова. Границы из `AGENTS.md`:

  ORC-сертификату порядок величин, а не строит VPP уровня ORC).

  малый ход, `src/lib/harbour-physics/`); гоночная физика, Тренажер, Основы,
  Лодка 3D и сервер мультиплеера не меняются.
- Нет спинакера, Code 0 и генакера; нет приливов и волн в модели хода (течение
  отдельно и аддитивно); нет 3D-заглушки Kenney в анатомии.

Отклонено в игре: музыка в гонке и платные наборы звуков (ADR-0019);
FFT-океан и EffectComposer (нет отката на WebGL2), тени картами теней; пятна
порывов и лейлайны до ADR о поле ветра; флот больше 5 лодок, инерция поворота
и публичные комнаты на два квартала; принудительная темная тема гонки;
копирование вида эталонной гонки (раскладка, плитки, иконки, бренд, мигания);
Unity; Swift-переписывание (mobile ADR-0007); новая декоративная анимация;
внешние ассеты в проде (CSP); новый подъем лимита JS.

Отклонено в контенте (`docs/design/books-audit-2026-09-26.md`, «Что НЕ
берем»): 3D-точки на GLB для мелких деталей, матрица целей трима в модуле и

рифа», дрилл «едва движется, но управляема» (в «Манёврах» он появится только
после пакета 6), миссия «чистый выход из поворота». Также декоративные
AI-картинки вместо проверенных схем, AI не определяет проводку и критерии
ответа, полное судейство RRS не изображаем.

Языковые исключения (не ошибки): курс sternik только на польском; радиофразы
английские; подписи на `/courses` по-русски намеренно; OG-картинки без
диакритики; `/stats` только по-русски; Основы на ES / FR / DE / IT с
английским HUD.
