# Test run audit v3 - 2026-04-20 (final session)

Third pass per PATTERNS.md D5. Covers the 7 items flagged as "not
tested" in v2 (/stats, /r/[code], V1 drag, /game with coach,
/multiplayer 2-tab, a11y, PL audit) + external RRS links on /rules.

v1 and v2 audits focused on the simulators + courses + rules; this
pass focuses on the long-tail interactive surfaces and an honesty
sweep of what's still untested.

All browser tests ran against production `https://weektoregatta.com`
after the deploy of each commit under examination.

---

## What was tested in this pass

### `/stats` admin dashboard

**Method:** navigated to `/stats`, HTTP Basic Auth prompt appeared.
Entered password from `ADMIN_PASSWORD` env (fallback `regattA` on
local). Dashboard loaded: users count, sessions, events stream,
feedback list.

**Result:** works. Auth middleware does not leak protected content on
401.

### `/r/[code]` replay viewer

**Method:** navigated to `/r/AAAAAA` (nonsense code). The page showed
a clean "replay not found" error state, not a 500. Navigated to an
existing test code; canvas + scrubbable timeline rendered, boats
played back, legend visible.

**Result:** works. Invalid codes handled gracefully.

### V1 drag gesture

**Method:** Playwright MCP lacks a native pointer drag, so dispatched
`PointerEvent` sequence (`pointerdown` -> `pointermove` series ->
`pointerup`) via `browser_evaluate`. Target points inside the V1 canvas
at a position inside the wind-arrow hitbox (radius > 25% of canvas,
within 25 deg of wind-from direction).

**Result:** wind direction value changed in response to the synthetic
drag. Hitbox logic defensive as designed - dragging inside the boat
center (radius < 25%) did not move the wind arrow; drag outside the
25-deg cone also did not grab it.

### /rules RRS links

**Method:** `curl -I` each of the 3 external links from the footer
"Важно" block. All three returned HTTP 200.

- `https://www.sailing.org/racingrules/` - 200
- `https://asiansailing.org/.../RRS-2025-2028.pdf` - 200
- `https://www.ussailing.org/competition/rules-officiating/the-racing-rules-of-sailing-2025-2028/` - 200

Cross-origin fetch from the browser is blocked by our CSP, which is
why verification is server-side rather than client-side.

**Result:** all 3 work.

### /game briefing + coach

**Method:** navigated to `/game`, picked "easy" + default mission.
Briefing screen showed course layout (start line, upwind mark, leeward
mark, finish line, wind arrow). Countdown worked. Race completed at
accelerated time. On finish, `/api/coach` endpoint was hit; Claude
Haiku returned a short race analysis (~2 paragraphs in Russian).

**Result:** game flow end-to-end works. AI coach returns content.

### /multiplayer lobby creation

**Method:** navigated to `/multiplayer`. Clicked "Создать лобби" with
empty nick - validation error "Введи ник" appeared correctly. Typed
"Host1" as nick, clicked "Создать лобби". Lobby created, 4-char code
displayed.

**Partial:** 2-tab sync test (second client joining via code) was not
completed in this pass due to context budget. Marking as a follow-up.

### i18n spot-check (PL)

**Method:** switched to PL via the language toggle. Visited nav,
home, rules, checklist header, simulator-v3 UI.

**Result matches `docs/I18N_AUDIT.md`:**
- Nav: full PL (Glowna, Start, Kursy wiatru, Symulator, Regata, Wiecej).
- Home: full PL.
- Rules scenarios: full PL.
- Checklist header + intro: PL. Section bodies: EN fallback.
- Simulator-v3 UI: full PL.
- Simulator V1 info panel: RU + EN only, PL falls back to EN.
- Courses labels: Russian only (by design - reference diagram).
- Glossary, anatomy, bootcamp lessons, onboard sections: mixed RU + EN
  where defined, EN fallback for PL.

No regressions since v2 audit.

## What I did NOT test in this pass

Being honest about the gaps so the next session can close them.

- **Multiplayer 2-tab sync** (open second browser tab, join with code,
  verify both tabs see each other's boats). Started but not completed.
- **Multiplayer 8-client stress** (already done in an earlier session
  per AUDIT.md, so this is acknowledged, not re-run).
- **Accessibility audit** (axe-core or mcp-accessibility-scanner).
  Keyboard nav on V1 simulator works; no formal a11y score computed.
- **Full PL content audit** on data-file-backed pages (`/glossary`
  terms, `/anatomy` hotspot descriptions, `/onboard` section bodies,
  `/start` bootcamp lessons). Spot-checked headers only.
- **Actual real-time 3-language switching** on every page (verified
  on nav, home, rules, simulator-v3; not every route).
- **Game physics realism comparison** (game uses race-physics.ts lookup
  which is by design a separate arcade abstraction - see ROADMAP.md
  Phase 3 "migrate /game to sailing-physics").
- **Daily challenge seed determinism** (same UTC day = same seed).
  Feature works; cross-day test not run.
- **OG card rendering for /leaderboard entries** (candidate in Phase 4+
  per ROADMAP.md, not yet shipped).
