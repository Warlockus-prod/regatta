# 3D scene update, 2026-09-07

## Scope

Shared website and app 3D simulator (`/simulator2`), yacht anatomy (`/anatomy`),
and the native WebView loader. iOS target: 1.6.1 (34).

## Implemented

- Responsive camera fitting with whole-yacht, sails and deck views; reset works
  even when the same preset is already selected.
- Clearer mobile layout: scene, speed/heel/heading, two primary sheets. Wind,
  reef, rudder and extra instruments live in expandable sections. Help is optional.
- Refined gelcoat and woven sail materials, procedural lighting and sky without
  external HDR downloads. Water detail is concentrated near the yacht and fades
  at distance. Wake particles use yacht-scale sizes and follow its heading.
- Yacht rotation follows the simulated heading; heel no longer applies tack sign
  twice. Waves use shared world coordinates. Main and jib have independent visual
  trim/luff state; main reef no longer furls the jib.
- Target speed and VMG respect reef; expensive target searches are cached by
  relevant conditions rather than recalculated every frame.
- Arrow keys on a slider no longer steer the boat. Pointer cancellation, focus
  loss and hidden tabs release held rudder input.
- Anatomy fits its actual asset bounds and shows only the selected part label.
  Shared cached GLB materials are no longer mutated by the anatomy viewer.
- Native 3D loading waits for `scene-ready`, allows 30 seconds for a cold load,
  and handles scene failure, HTTP failure and terminated WebView processes.
  Retry remounts the view; other simulator tiers preserve their ready contract.
- Default lighter graphics in the app. Optional desktop postprocessing;
  memoized scene prevents telemetry from repeatedly rebuilding render settings.

## Limits and next steps

The existing GLB hull and rig are preserved. Sail surfaces are now generated
and deformed in code with fixed luff/head/tack anchors. Blender 5.1.1 can import
the source asset; no Blender export is required for this correction.
A further modeling pass can improve railings, ropes, fittings and close-up hull
silhouette, with explicit triangle/draw-call budgets. This is an educational
sailing approximation, not a hydrodynamic or navigation-grade model.

The live 3D scene requires internet. Browser checks do not establish performance
on every physical phone; actual hardware FPS and battery measurements remain a
separate task. Broad site navigation/onboarding findings remain in
`docs/project-audit-2026-09-07.md`; this release addresses the 3D module.

## Follow-up from owner screenshots

The owner identified an incorrect flying jib and unreadable Trainer elevations.
The first visual pass did not catch the jib detaching from the forestay when
viewed from the other side. Corrections:

- Jib rotates about the inclined forestay, not a vertical axis at the bow.
- Parametric cloth replaces the old unanchored morph targets. Draft and twist
  mirror with the tack; luff/head/corners stay fixed; the main reefs down toward
  the boom. Surface seams follow deformation. Floating rigid sail decoration
  is hidden rather than left detached from the new surface.
- Main and jib sheet lines now follow the boom/clew instead of staying in
  the original static GLB pose.
- Local Node CPU benchmark: 1,000 warmed updates of both cloth surfaces and
  seams averaged 0.45 ms per update, 693 vertices / 1,260 triangles per sail.
  Geometry updates at 30 Hz; this benchmark does not measure GPU or phone FPS.
- Three regression tests cover forestay attachment through rotation and flutter,
  main luff/clew anchors through reefing, and mirrored shape on opposite tacks.
- `/simulator-v3` rear view is now an actual transom section with signed heel.
  Side view is an orthographic profile. No mirrored underwater sail shapes.
  Main and jib have distinct colors, compact legends and view-specific guidance.
  Top view retains the detailed angle/optimum overlay; its optimum checkbox is
  only shown there. The new elevations support reefing and jib opening.
- Browser smoke now switches rear/side views and verifies R2 reef feedback.
