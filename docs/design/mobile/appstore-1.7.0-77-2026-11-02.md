очень старая лежит» (публичная была 1.6.4, сборка 48 от 2026-10-18). Это
ответ на [Р-29] (срок публичного выпуска): сейчас, не после пакета 22.

## Сборка

- Исходник: `55a0c061` ветки `claude/app-next` (пакеты 6-11 плюс подготовка
  выпуска). Номер сборки 77, поезд 1.7.0.
- Без тестового раздела «Реклама»: `EXPO_PUBLIC_ADS_DEMO` не задан, поэтому
  `mobile/plugins/with-vox-sdk.js` исключает `vox-ads` и `vox-prebid` из
  автолинковки, а в Настройках нет входа «Ads»
  (`mobile/src/config/ads-demo.ts`). Причина: VOX SDK объявляет сбор данных
  для сторонней рекламы, а README модуля запрещает App Store без своих
  плейсментов, согласия и обновленной метки приватности; описание и заметки
  для ревью обещают «без рекламы». В бинарнике 0 строк VOXAds, hybrid.ai,
  PrebidMobile, нет их манифестов приватности; Podfile.lock без VOX и Prebid.
- `expo prebuild --clean`, `pod install`, Release-архив Xcode 27.2 (27B52),
  SDK 24B8118. IPA 30,4 МБ (76 было 33,6 МБ с рекламой).
