на телефоне, кампании запускаем отдельно. Сборка 75 = сборка 74 (`main`,
`9b061c06`) плюс ветка `claude/ads-formats`.

## Что вошло

- Настройки > Реклама: список форматов вместо одной 3D-сцены. Баннеры 320x50,
  300x250, 320x480, 300x600, 728x90 (листаются), полноэкранная, видео с
  наградой, видео VAST в контенте и 3D in-game с тестовыми щитами.
- Реклама идет через VOX SDK 1 (`GET https://ssp.hybrid.ai/auction/getad`) по
  своим местам приложения `App · WTR` из кабинета VOX. Под каждой рекламой
  адрес, ID места, статус и время; без рекламы видна рамка реального размера.
- Pod VOXSDK закреплен на `vox-sdk-ios` `fc523af` (ветка
  `fix/in-app-ads-2026-10-30`): viewport баннера, полноэкранная по центру,
  видео VAST XML, «нет рекламы» без повторов, без цикла удержания.
- VOX SDK 2 в релизной сборке скрыт: его Prebid Server запущен на Mac
  (localhost), телефон до него не достанет. В симуляторе (debug) он остается.
- Реклама есть только в этом разделе (Jest-тест держит мосты внутри раздела).
