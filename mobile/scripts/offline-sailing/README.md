# Shared offline sailing package

`node mobile/scripts/build-sailing-offline.mjs` compiles the original Basics,
Trainer, 3D Boat, solo race and Anatomy React pages into one self-contained
`mobile/assets/sailing-offline.html`. No course, physics or model copy is kept
here. The manifest records source and embedded asset hashes, five supported
routes, package version and the original and WebKit-ready yacht hashes.
`--check` verifies exact generated bytes; `--validate` compiles without writing.
The existing package budget is 8 MiB.

The native `SimWebView` selects a page before scripts execute:

```js
window.__REGATTA_EMBED__ = { path: "/anatomy", query: "lang=it" };
window.__REGATTA_LANGUAGE__ = "it";
```

Supported paths are `/simulator`, `/simulator-v3`, `/simulator2`, `/game` and
`/anatomy`. The original query is preserved and embed/offline flags are forced
on. The same `regatta-embed` and `regatta-language` events update a mounted
page. Existing controls preferences, trainer checkpoints and race messages
retain their native bridges. Basics and Anatomy add no storage keys or cloud
dependency. The native simplified Basics and Anatomy diagram remain fallback
routes if WebView rendering itself fails.

For a static local preview use `sailing-offline.html?screen=basics&lang=pl`
or `?screen=anatomy&lang=it`. Existing `trainer`, `boat3d` and `game` aliases
remain available. The default remains 3D Boat.

Anatomy uses the same embedded Blender yacht. All eight original poster JPGs
are embedded; the source intentionally shows these posters only in Russian
and English, while model labels and descriptions remain in all seven languages.
Copied poster URLs point to the public Anatomy page. Content pages keep
document scrolling and the original poster scroll lock; sailing scenes keep
their fixed viewport. The CSP blocks HTTP resources, and all fonts and yacht
textures are embedded as data URLs.

Targeted tests: from `mobile`, run
`npm test -- --runInBand scripts/offline-sailing __tests__/offline-sailing-i18n.test.tsx`.
The web `src/features/simulator-3d/offline-asset.test.ts` also validates the
unchanged GLB node/mesh and texture content contract.
