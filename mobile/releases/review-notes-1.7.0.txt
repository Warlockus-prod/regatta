Week to Regatta is an educational sailing app. No account, sign-in or test credentials are required. Version 1.7.0 build 59 includes the following local features:

1. The Race section opens the same bundled 3D solo race for Solo, daily challenges and missions. Simple uses automatic sail trim; Pro uses manual mainsheet and jib-sheet controls. History, replay, penalties and coaching are stored and calculated locally. Multiplayer is a separate online room.

2. The Practice section contains bundled Basics, sail-trim and 3D boat trainers. Menu also exposes the bundled 3D yacht anatomy viewer. Controls sit below the boat; wheels are the default, and sliders remain selectable. Trainers support landscape. Sailing lessons can open the matching trainer and return to the lesson.

3. Learn / SRC radio contains the full bundled course, device lessons, simulator, theory, question practice, position practice and live-dialogue exercises. UI and study material are adapted to Russian, English, Polish, Spanish, French, German and Italian. The official Polish question original remains accessible. Standard English on-air phrases and English grammar exercise choices remain English intentionally.

4. SRC microphone practice starts only after the learner explicitly requests it. It requires an installed compatible English on-device recognition model and microphone permission. The app does not automatically download a model, send the audio to a speech server or persist an audio file. If the device cannot provide local recognition or permission is denied, a labelled typed-content check remains available offline; typing is not presented as a successful microphone test. Station speech uses an installed matching system voice; unavailable speech is not represented as audible playback.

5. Learn / Motorboat skipper opens the bundled Polish Sternik course: 879 source questions, theory, tests, a 75-question/90-minute mock exam and typed oral-answer practice assessed against a local rubric. This course intentionally remains Polish-only. Its oral-practice screen takes typed answers, requires no microphone and makes no transcription request. The app provides educational practice, not certification or an official examination service.

Privacy: no advertising or cross-app tracking. Pseudonymous product analytics (PostHog EU, random install identifier) are on by default and can be disabled in Settings > Data > Anonymous analytics. That switch also covers embedded course pages. Local learning/race progress remains on the device. Settings > Data > Clear all data clears the local progress while preserving an analytics opt-out. Existing progress can be imported on-device without an HTTP request.

Optional online features remain separate: live multiplayer, Ask the assistant, spot weather and remote gallery/video content require a connection. Website and older-app online radio/Sternik voice practice send a recording explicitly started by the user through our server to OpenAI for transcription, without storing the recording or transcript in our database. These supported online modes explain the retained Audio Data App Privacy declaration; they are not a server fallback for the new bundled SRC recognizer.

The interface has light learning pages and dark instrument screens. No demonstration data or login is required to reach the features above. The latest screenshots and release-binary verification are recorded separately in the build journal.
